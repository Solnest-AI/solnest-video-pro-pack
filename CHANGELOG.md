# Changelog

## 1.0.0

First release.
- Nine video skills in one install: HeyGen avatar, HeyGen video, HeyGen translate, the explainer, Duo, 3D captions, session story, day in my life, and the Seedance cinematic prompt writer.
- Install by pasting the repo link into Claude Code and saying "set this up".
- The pack lives in `solnest/video-pro-pack` in your home folder. Setup copies each skill into Claude Code and installs HyperFrames from HeyGen.
- Updates install themselves once a day, in the background, from published releases only. If a new release does not load, the old one is put back by itself.
- An update never touches your avatars, your video projects, your sign-ins or any file you added. Changes you ask for are kept in `~/.solnest/video-pro-pack/my-instructions.md`.
- If you already have one of these skills from another installer, the pack leaves your copy alone.
